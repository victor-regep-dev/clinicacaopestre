# Caopestre Clínica Veterinária — Site

Site institucional estático (HTML/CSS/JS puro).

## Publicar no Vercel
1. Acesse https://vercel.com e faça login.
2. Clique em **Add New > Project** e importe este projeto
   (ou arraste a pasta no **Vercel CLI**: `vercel --prod`).
3. Framework Preset: **Other** (site estático). Não há build.
4. Deploy. Pronto.

## Estrutura
- index.html       -> página única
- assets/          -> imagens (logo, hero, equipe, consultório)
- vercel.json      -> URLs limpas + cache de assets
